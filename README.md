# 🤖 ربات فروش اشتراک VPN (تلگرام)

ربات تلگرام فارسی برای فروش اشتراک VPN، سیستم دعوت دوستان و دریافت کانفیگ رایگان با سکه.
ساخته‌شده با **Python + aiogram 3** و **SQLite** — آماده برای دیپلوی روی **Railway**.

---

## ✨ امکانات

- ثبت خودکار کاربر در دیتابیس هنگام `/start` + لینک دعوت اختصاصی
- سیستم دعوت دوستان با سکه (هر دعوت موفق = 1 سکه) + ضدتقلب (هر کاربر فقط یک‌بار محاسبه می‌شود)
- دریافت کانفیگ رایگان از بانک کانفیگ (با حداقل 5 سکه)
- فروش اشتراک VPN با نمایش اطلاعات پرداخت قابل تغییر از پنل
- ثبت سفارش با ارسال رسید پرداخت + اعلان به ادمین
- تایید/رد سفارش از داخل ربات با ارسال کانفیگ یا دلیل رد
- بخش «سفارش‌های من»، «قوانین» (قابل ویرایش)، «پشتیبانی» (چت دو طرفه با ادمین)
- پنل مدیریت کامل **داخل خود ربات** (دستور `/admin`) — فقط برای ADMIN_ID

---

## ⚙️ راه‌اندازی محلی

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن ربات شما"
export ADMIN_ID="آیدی عددی تلگرام شما"
python main.py
```

## 🚀 دیپلوی روی Railway

1. این پوشه را به یک ریپازیتوری گیت‌هاب پوش کنید.
2. در Railway یک پروژه جدید از روی این ریپازیتوری بسازید (New Project → Deploy from GitHub repo).
3. در بخش **Variables** متغیرهای زیر را اضافه کنید:
   - `BOT_TOKEN` → توکن ربات (از @BotFather)
   - `ADMIN_ID` → آیدی عددی شما در تلگرام (از @userinfobot)
4. Railway به صورت خودکار `Procfile` را تشخیص داده و ربات را به‌صورت **Worker** اجرا می‌کند.
5. دیتابیس SQLite به‌صورت فایل `bot.db` در همان کانتینر ساخته می‌شود.

> ⚠️ نکته: در پلن‌های رایگان Railway، فایل‌سیستم پایدار نیست و با هر دیپلوی جدید ممکن است دیتابیس ریست شود.
> برای حفظ داده‌ها در محیط پروداکشن، یک **Volume** برای مسیر دیتابیس به سرویس اضافه کنید
> یا متغیر `DB_PATH` را به مسیر داخل Volume تنظیم کنید.

## 🔧 متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام (الزامی) |
| `ADMIN_ID` | آیدی عددی ادمین (الزامی) |
| `DB_PATH` | مسیر فایل دیتابیس (پیش‌فرض: `bot.db`) |

## 🛠 پنل مدیریت

با ارسال دستور `/admin` (فقط توسط ADMIN_ID) منوی زیر باز می‌شود:

- 📥 **سفارش‌های در انتظار** — مشاهده و تایید/رد سفارش‌ها
- 💳 **تنظیم اطلاعات پرداخت** — تغییر شماره کارت و نام صاحب کارت
- 📜 **ویرایش قوانین** — تغییر متن صفحه قوانین
- ➕ **افزودن کانفیگ رایگان** — افزودن کانفیگ به بانک کانفیگ رایگان
- 📊 **آمار ربات** — تعداد کاربران، سفارش‌ها و کانفیگ‌های موجود

### پاسخ به پشتیبانی
وقتی کاربری پیام پشتیبانی می‌فرستد، برای ادمین دو پیام ارسال می‌شود: یک پیام هدر (شامل آیدی کاربر) و سپس کپی پیام کاربر.
برای پاسخ، روی پیام **هدر** (یا پیام کپی‌شده‌ای که زیر آن آیدی کاربر درج شده) ریپلای کنید — پاسخ مستقیماً برای کاربر ارسال می‌شود.
